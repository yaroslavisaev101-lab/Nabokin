# NabokinAuto — новый сайт

## Структура
```
index.html         главная
cars.html           каталог (примеры подбора)
calculator.html      калькулятор стоимости
news.html            новости (тянутся из админ-панели)
reviews.html         отзывы (тянутся из админ-панели + форма добавления)
contacts.html        отдельная страница «Контакты»
admin.html           редирект на /admin/
admin/index.html     админ-панель (пароль)
css/style.css        вся стилистика, тёмная и светлая тема
js/store.js          хранилище данных (localStorage)
js/theme.js          переключение темы
js/main.js           шапка, подвал, меню, модальные окна, тосты
js/admin.js          логика админ-панели
images/nabokin-logo.png   логотип (замените на свой файл с тем же именем)
```

## Как открыть
Просто откройте `index.html` в браузере, либо загрузите папку целиком в репозиторий
GitHub и включите GitHub Pages (Settings → Pages → Deploy from branch).

## Админ-панель
Адрес: `ваш-сайт/admin/` (или `admin.html` — сработает так же).
Пароль по умолчанию: **nabokin2026** — смените его сразу в разделе «Настройки».

В админ-панели можно:
- смотреть все сообщения с сайта (заказ авто, консультация, вопрос, калькулятор, «Написать нам»);
- публиковать и удалять новости (заголовок + фото);
- удалять отзывы;
- менять тексты (заголовки, контакты, юр. данные);
- менять логотип;
- менять пароль и сбрасывать данные.

## ⚠️ Важное ограничение, о котором нужно знать
Сайт на GitHub Pages — **статический**, без сервера и базы данных. Поэтому все данные
(пароль, новости, отзывы, сообщения, тексты) хранятся в `localStorage` **того браузера**,
в котором вы вошли в админ-панель.

Это значит:
- Если вы зайдёте в админ-панель с другого телефона/компьютера — вы не увидите там
  сообщения, оставленные на сайте другими посетителями, и наоборот.
- Реальные посетители сайта не получат ваши изменения текста/фото/новостей, если
  зашли **до** того, как вы их сохранили в своём браузере — эти изменения видны только
  вам, пока сайт не подключён к общему хранилищу.

Для проекта-визитки или демонстрации клиенту этого достаточно. Если нужно, чтобы
сообщения реально приходили от **любого** посетителя и админ видел их с любого
устройства — понадобится подключить бесплатный backend (например, Firebase или
Supabase: база данных + хранение фото + защищённый вход). Могу собрать эту версию
отдельно, если решите, что она нужна — просто скажите, и я это сделаю.

## Замена логотипа
Проще всего — через админ-панель (раздел «Фото»): выберите файл, он сохранится
в браузере. Либо замените файл `images/nabokin-logo.png` на свой (то же имя,
желательно квадратное изображение).
